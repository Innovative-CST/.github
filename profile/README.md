### LogicodeumIDE - Private
Old Name: Android AppStudio

<a href="https://github.com/Innovative-CST/LogicodiumIDE">
        <img style="padding:5px;" width="70dp" height="70dp" src="https://images.weserv.nl/?url=https://github.com/Innovative-CST/.github/blob/main/profile/logicodeumide.png?raw=true?v=4&h=250&w=250&fit=cover&mask=circle&maxage=7d"/>
</a>

This project enables building Android applications using a drag-and-drop interface. Currently this app is under development stage.

- Repositories belongs to this project :
  - [LogicodeumIDE](https://github.com/Innovative-CST/LogicodiumIDE) - New Main app repository.
  - [AndroidAppStudio](https://github.com/Innovative-CST/AndroidAppStudio) - Old Main app repository (1400+ commits).
  - [LogicodeumIDE Backend](https://github.com/Innovative-CST/logicodeumide-backend) - Backend for LogicodeumIDE written in Typescript using Express, Mongo MySQL database. Handles sending emails and payment gateway for purchase.
  - [blockidle-plugin-api](https://github.com/Innovative-CST/blockidle-plugin-api) - SDK for building plugins (deprecated as merged in main project)
  - [plugin-builder](https://github.com/Innovative-CST/plugin-builder) Gradle plugin for building extensble plugins for block idle (deprecated)
